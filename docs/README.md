# 文档导航

日常 SDK 接入只需阅读仓库根目录的 [中文调用手册](../README.md)，其中包含各功能的调用示例和三个完整组合程序。这里按用途保留补充资料，不重复维护另一份调用手册。

| 文档 | 适用场景 |
| --- | --- |
| [运行语义与数据安全](runtime.md) | 查阅响应、内存、分页、批删、重试、取消、分片恢复与下载断点的精确边界 |
| [协议说明与能力限制](protocol.md) | 核对原始资料中的冲突、OAuth/CDN 采用依据和未提供能力 |
| [0.2 迁移指南](migration.md) | 从旧构造器、配置、结果与错误类型迁移 |
| [CLI 使用手册](cli.md) | 从命令行操作 Bucket 和对象 |
| [验证指南](validation.md) | 运行本地检查、真实服务 smoke、OAuth 验证和下载基准 |
| [原始 API 索引](open_api/README.md) | 按功能查找 35 份 YAML、33 项操作的 SDK 映射与文件摘要 |

## 资料维护

- 新增或调整调用方法，更新根 README；精确的资源和恢复边界更新运行语义。
- 协议有冲突时保留原始 YAML，在协议说明中写明依据和适用限制。
- 增加或替换 YAML 时同步修改索引、SDK 映射与摘要，并复核覆盖检查的文件数量。
- 验证指南只记录可重复执行的方法，不堆积每轮测试数量、分支、工单或交付记录。

修改后在仓库根目录执行：

```sh
python3 scripts/check_docs.py
python3 scripts/check_coverage.py
```
